Coquena

Your own language model server, on your machine, without fighting the configuration.

DownloadVersion 0.1.0 · Windows x64

What it does

Picks the right engine

Detects your hardware and installs the matching official llama.cpp build, for CPU, NVIDIA (CUDA), or Vulkan.

Download models with confidence

Choose GGUF models from Hugging Face. Coquena verifies every file, handles models split into parts, and lets you pause and resume downloads.

Keeps your settings

Each model becomes a preset with its parameters. No more long command lines or scripts to maintain.

One server, many models

Expose several presets behind a single local server and pick the model from your app.

You stay in control

Run it in the foreground or in the background, stop it, restart it, and check metrics and logs whenever you need.

Requirements

  • 64-bit Windows (x64).
  • No .NET installation required.
  • Disk space and memory depending on the models you choose.

Getting started

  1. Install the engine that fits your machine

    .\coquena.exe backend install

  2. Download a model

    .\coquena.exe model download user/repository

  3. Create a preset and add it to the server

    .\coquena.exe preset create user/repository:quantization my-model
.\coquena.exe server default preset add my-model

  4. Start the server

    .\coquena.exe server default start -d

With the default settings, the server listens on http://127.0.0.1:9931. Use my-model as the model name in any client compatible with the llama.cpp API.

Why Coquena

In Andean folklore, Coquena is a small shepherd who looks after the mountain’s animals. The name brings that image to llama.cpp: a guardian that looks after your “llamas,” keeps them organized, respects your machine’s resources, and gets their environment ready for work.
