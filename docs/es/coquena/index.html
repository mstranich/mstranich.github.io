Coquena

Tu propio servidor de modelos de lenguaje, en tu máquina y sin pelearte con la configuración.

DescargarVersión 0.1.0 · Windows x64

Qué hace

Elegí el motor adecuado

Detecta tu hardware e instala la versión oficial de llama.cpp que le corresponde, para CPU, NVIDIA (CUDA) o Vulkan.

Descargá modelos con confianza

Elegí modelos GGUF de Hugging Face. Coquena verifica cada archivo, une los modelos divididos en partes y permite pausar y retomar descargas.

Guardá tu configuración

Cada modelo queda como un preset con sus parámetros. No más líneas de comando largas ni scripts que mantener.

Un servidor, varios modelos

Publicá varios presets detrás de un único servidor local y elegí el modelo desde tu aplicación.

Lo controlás todo

Arrancalo en primer plano o en segundo plano, detenelo, reinicialo y consultá métricas y logs cuando lo necesites.

Requisitos

  • Windows de 64 bits (x64).
  • No hace falta instalar .NET.
  • Espacio en disco y memoria según los modelos que elijas.

Primeros pasos

  1. Instalá el motor compatible con tu equipo

    .\coquena.exe backend install

  2. Descargá un modelo

    .\coquena.exe model download usuario/repositorio

  3. Creá un preset y sumalo al servidor

    .\coquena.exe preset create usuario/repositorio:cuantizacion mi-modelo
.\coquena.exe server default preset add mi-modelo

  4. Arrancá el servidor

    .\coquena.exe server default start -d

Con la configuración inicial, el servidor queda escuchando en http://127.0.0.1:9931. Usá mi-modelo como nombre de modelo en cualquier cliente compatible con la API de llama.cpp.

Por qué Coquena

En el folclore andino, el Coquena es un pequeño pastor que cuida a los animales del cerro. El nombre lleva esa imagen a llama.cpp: un guardián que cuida tus “llamas”, las mantiene en orden, respeta los recursos de tu máquina y les prepara el terreno para trabajar.
